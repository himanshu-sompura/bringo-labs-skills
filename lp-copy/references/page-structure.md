# Landing page structure

Use for a full page or a section-order change. Build the outline in mobile reading order with one line per block: **buyer question → answer or evidence → placement**.

Start with **offer → strongest unresolved doubt → remaining decision details → action**. Give ready buyers an early route. Change the order when the visitor needs a particular answer sooner.

| Buyer needs next | Put early |
| --- | --- |
| The specific offer promised by the ad | The exact deliverable and advertised price, date, or eligibility where applicable. A short signup form can sit in the hero when visitors already know what they get. |
| A reason to believe the mechanism | A concrete step, product view, or sample deliverable. Keep the evidence beside the mechanism it supports. |
| Confidence that it works in their situation | The closest relevant result or demo, with the context needed to interpret it. |
| A decision on fit, cost, effort, or timing | The decisive condition before the form, purchase, or other commitment. |

Combine blocks that answer the same question. Split a block when two answers need to be easy to find independently. Keep material price, conditions, and proof in the main flow. Reserve FAQs and accordions for remaining questions. Repeat the same primary action where an answer gives the buyer a new reason to act.

## Check the reading order

- On the first screen, give the offer and action priority over imagery or badge rows. Let the next heading signal what follows.
- Skim headings and button labels in mobile order. Use headings that answer real questions. Keep captions with evidence, terms with the affected decision, and CTA notes beside the button. Inspect actual layout if available.
- Read the end of one section with the next heading. If the connection is clear, skip the bridge. If the move feels abrupt, reuse the relevant detail in the heading or move the next answer earlier. Replace “The results” with the specific result or capability the section explains.
- Use one reading column for an argument, steps for a sequence, and side-by-side content for a meaningful comparison. Preserve the comparison when columns stack.
