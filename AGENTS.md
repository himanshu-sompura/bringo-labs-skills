# Bringo Labs skill publishing

- Publish skill changes to GitHub's `main` branch and verify the published files.
- After every GitHub skill publish, update the matching Notion **Skills Backlog** entry in the same task. Keep the skill name, existing status or category as appropriate, and canonical GitHub folder link current. Update the existing entry when renaming a skill.
- Keep Notion as an index. Store the skill instructions and references in GitHub. Verify the Notion entry before marking the work complete.
